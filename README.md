# 生物研习室 · 全25题

高中生物自主学习网页：阅读原题、点选或输入答案、完成电泳条带、累计积分，并按需查看解析和课本知识。

- 56个计分步骤，按答对比例折算为百分制，保留1位小数，满分100分；错题可重试，不重复计分。
- 展开解析后可对照原题：电脑左右并排，手机上下分区，两侧独立滚动。
- 逐项解析采用“题目依据 → 推理过程 → 结论”。第8题补充逐一假设、亲子矛盾、基因来源和加权概率，并同步老师详解与原系谱分步图解。
- 225段老师声音讲解；选项解析与关联知识分别录制；知识卡默认收起，展开后可独立播放。
- 25题专属图解，75个分步画面，支持逐步切换和自动演示；综合题完成各小问后解锁整题图解。
- “着丝粒”使用 zhuó sī lì 的读音。
- 填写班级姓名，按累计答对步骤生成称号卡，可下载高清 PNG 或按 A5 横向打印。
- 进度和班级姓名仅保存在学生自己的浏览器中，无需注册。

本仓库仅含网页所需文件、题图和讲解音频，不包含声音克隆的原始参考录音。

GitHub Pages 从 main 分支根目录发布。静态文件均使用相对路径。
